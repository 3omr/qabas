# Agent Note: Qabas 桌面标识保留已安装数据

Status: implemented

[English](2026-10-05-qabas-desktop-identity.md) | 中文

## 问题

Qabas 的学习界面和引擎由桌面宿主分发，但安装程序、菜单和模型可见的桌面说明标识了另一个产品。更改应用标识符还会把设置和凭据移到另一个应用数据目录。

## 决策

安装程序、原生窗口、菜单、通知、加载页面、发行标题和桌面系统提示上下文使用 Qabas。Tauri 标识符保持为 `io.github.bestbbb.harness-desktop`；内部包名和运行时输出所有权标记保留原有名称。[桌面分发覆盖层](../process/2026-08-21-upstream-rc1-desktop-sync.zh.md) 继续负责启动和打包。

安装图标、托盘模板、桌面后备标记和浏览器网站图标共用 Qabas 火焰几何形状。原生图标使用固定颜色及留白；浏览器 SVG 根据主题调整颜色。托盘模板保持透明和单色。

## 考虑过的替代方案

**随产品一起更改标识符。** 拒绝，因为更改应用数据位置会让已有设置和凭据不可用，除非另外进行迁移。

**在原生界面保留继承的名称。** 拒绝，因为学生安装的是 Qabas，窗口、安装程序和说明需要标识同一个应用。

## 后果

已有安装保留原有应用数据位置。根目录的阿拉伯语 README 介绍 Windows 安装并链接引擎和桌面指南；文档翻译仍由各自的双语文档对负责。原生品牌有单元测试，桌面上下文有录制会话的预期输出。
