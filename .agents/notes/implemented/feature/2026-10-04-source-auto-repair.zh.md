# Agent Note: 按讲座范围自动修复来源

Status: implemented

[English](2026-10-04-source-auto-repair.md) | 中文

## Problem

无人值守的讲座任务可能已完成起草和审阅，却因另一讲座的手写 PDF 缺少可搜索文字而在定稿时失败。辅助文档不足以成为放弃一份已有可用录音依据的转写稿的理由。

## Decision

[引擎](../../../../engine/README.md#source-auto-repair)在执行准备工作前确定选定来源的范围。无关来源不进入修复执行，失败或仅计划的准备结果不能上传。准备错误关联到原始路径。

引擎先运行本地 OCR，再通过 Gemini/agy 在限定范围内读取页面图像。词置信度低于 60/100 时拒绝薄弱的本地 OCR；PDF 置信度检查覆盖前三页。私有临时目录仅包含复制或渲染的图像。提示词只允许读取这些图像，并要求按页忠实转写和标记无法辨认的文字。校验拒绝空内容、仅拒绝说明、缺页或乱序页面。缓存 Markdown 记录模型和手写转写来源，可搜索 PDF 将文字送入现有上传实现。内容哈希防止复用过期结果；失败也会缓存，以免无人值守任务反复尝试。

选定的清单条目授权上传符合条件的准备结果，无需第二份上传批准列表。明确的讲座清单独立于模块级同步检查点，使用当前 phase-0 校验。无法读取的辅助文档产生省略警告，包括选定幻灯片。录音和已分类的考试卷、题库仍是必需来源。成功的 MCP 结果将警告送入持久化的资料库任务备注，包括嵌套调用和定稿后的提供方错误。

## Alternatives considered

**让每份本地文档都阻断任务。** 这会把讲座与无关文件绑定，并在起草和审阅通过后阻止完成。

**上传无法读取的原文件或编造文字。** 两者都不能提供可靠证据。失败的辅助来源被省略；模型文字明确标注来源，不确定的词保留无法辨认标记。

**修复整个模块的所有来源或替代模块级批准。** 这会为无关学生资料消耗模型读取。讲座范围控制修复；明确的模块同步保留批准要求，并对未解决文件返回部分完成结果。

## Consequences

[任务完成策略](2026-10-04-part-progress-and-finalized-jobs.zh.md)和[图像验证策略](2026-10-04-web-figures.zh.md)仍然有效；本笔记不取代其中任何一项。结构校验无法证明手写识别准确，也无法证明模型没有概括。没有安全转换器的格式、缺少 agy、读取被拒绝和不可用响应都会减少辅助证据。必需权威来源、无效清单、歧义匹配和远端失败仍会停止任务。

临时目录中的合成 PDF、图像及假的外部命令覆盖按范围上传、可用模型文字、成功和失败缓存、转换、页数与时间限制、辅助来源警告及必需来源拒绝。launcher 子进程覆盖模块同步失败但存在明确讲座清单的情形。记录的客户端 Session 事件固定警告到任务备注的投影、完成及重新加载行为。针对所提供私有样本的真实 agy 验收被主机对 CLI 日志和本地服务器启动的限制阻断；尚未确认真实手写识别准确性。
