# Agent Note: Source-grounded external illustrations

Status: implemented

[English](2026-10-04-web-figures.md) | 中文

## 问题

医生描述的视觉区别可能未出现在讲座幻灯片中。无关或错误的医学照片即使配有看似恰当的说明，也可能教授错误体征。

## 决策

[引擎](../../../../engine/README.md#external-illustrations)解析结构化指南占位符，其中包含英文描述、搜索短语与讲座原文依据。精确摘录依据与每堂讲座五张图像的上限先于可选 Commons 访问。机器可读许可名称与匹配的许可 URL 将复用限制为 CC0、Public domain、CC BY 和 CC BY-SA。

Gemini 通过 agy 查看候选图像及所有提供的提取幻灯片图像。严格且高置信度的 yes 才批准医学外观与视觉缺口；其他结果均省略图像。工作目录仅包含复制的图像。已安装的 agy 二进制暴露 `multimodal_view_file`；假模型测试不证明真实可用性或模型判断。缓存复用要求描述、原文依据及幻灯片字节相同。

批准的原图与署名元数据共用讲座插图目录，因此已有的最终转写回收事务共同管理它们。独立清单与阿拉伯语标签区分外部教学插图和医生幻灯片。图像替换改变草稿字节，因此保存的恢复指纹与分段长度描述解析后的草稿。插图请求与署名不计入讲述内容下限。每个工作区的开关在解析时同时抑制写作请求与网络/模型调用。

## 考虑过的替代方案

**以搜索相关性作为批准。** 医学相关标题不能证明图像展示了什么。读取本地图像与保守置信度阈值可防止这种不匹配。

**通用图片搜索与不确定许可。** 抓取和不可验证的复用条款不符合所有者许可要求。Commons API 提供机器可读元数据；未知许可被拒绝。

**Gemini API 密钥回退。** 已安装的 agy 二进制包含多模态文件读取器，因此无需第二条凭据路径。权限拒绝或图像读取不可用时省略图像。

## 后果

离线访问、元数据缺失、原图过大、不确定的视觉判断及工具读取被拒绝都会减少插图覆盖，但不阻止讲座运行。无需新增图像缩放依赖。高置信度模型仍可能误认医学图像；引擎保留其回答与来源署名以供审查，不声称真实医学准确性。

本记录补充外部图像批准策略，不替代任何现行 Agent Note。假 HTTP/模型测试覆盖批准与拒绝、有界读取、原文依据、渲染、验证拒绝、设置及回收恢复。按要求，英中对应文档位于 `engine/`。
