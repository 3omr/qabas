# Agent Note: 截断工具调用的纠正性恢复

Status: implemented

[English](2026-10-02-truncated-tool-call-recovery.md) | 中文

## 问题

很长的阿拉伯语 stage_draft_part 调用可能达到 Gemini 输出限制，或在 Google SDK 未完成的 JSON 片段中结束。通用 PI_AI_ERROR 会终止讲座任务，未要求模型生成更小的部分。重复同一请求会消耗稀缺的每日额度，却不改变过大的输出。

## 决策

pi-ai 适配器将输出受限工具调用与解析器 EOF 诊断归类为 TOOL_CALL_TRUNCATED。已暴露调用的诊断保留工具名称与流式传递的原始参数大小。Agent-loop 提交部分助手消息、失败调用、纠正工具结果与 llm/tool-call-truncated 通知，而不执行部分参数。下一步骤从这些记录派生改变后的历史。同一工具在一个轮次中连续第二次截断会以明确错误结束轮次；该工具的正常步骤会重置计数。同一响应中同一工具的多个调用只计一次。即使此前的纯文本响应达到输出上限，恢复截断仍要求进入下一步骤。

Google SDK 在 pi-ai 暴露函数调用前缓冲完整 JSON 片段。因此，丢弃的片段没有可用的工具身份或参数大小。此情况提交 assistant/attempt 与纠正性用户指令，通知中的工具和大小为 null，并使用独立的两次响应上限。循环不虚构调用 ID 或部分参数。显式取消与其他提供方错误保留原有处理。

通知是读取时必需的会话词汇。模型可见纠正内容属于普通助手／工具结果或用户消息事件，因此回放与恢复可重建它。英语、中文与埃及阿拉伯语 Chat 字典拥有独立对话提示。原始字符数使用 UTF-16 代码单元，与 JavaScript 字符串长度一致；它不是字节或 token 估计。

## 考虑过的替代方案

**盲目重试请求。** 未采用，因为未改变的模型输入容易生成同样过大的工具调用，并再次消耗免费额度。纠正反馈必须到达下一请求。

**执行解析器修复的部分对象。** 未采用，因为语法修复后的 JSON 可能悄悄遗漏讲座内容。截断响应绝不执行工具。

**SDK 未暴露调用时仍要求工具结果。** 未采用，因为 harness 没有权威的调用 ID、名称或参数字节。持久纠正指令可恢复任务，而不虚构提供方数据。

## 影响

连续截断后，恢复最多增加一次纠正请求，并保留仅追加请求前缀。已暴露的部分参数在压缩前保留于持久历史；SDK 缓冲字节不可用，因此不声称其大小。原始提供方结束状态保留在助手流中，而轮次可在纠正后正常完成。

[终止流失败决策](../architecture/2026-07-29-terminal-llm-stream-failures.zh.md)继续拥有适配器规范化与普通失败尝试；截断输出是明确的纠正历史例外。[每日额度回退](2026-10-02-daily-quota-model-fallback.zh.md)继续拥有路由切换，绝不负责此输出修复。这两个决策都未被完全取代。

## 验证

适配器测试覆盖长阿拉伯语不完整 JSON 增量、长度停止、无终止事件的流 EOF、Google SDK 缓冲失败与普通错误。真实 Loader 组合覆盖纠正后工具执行、第二次失败上限、成功工具重置、独立工具计数与不可用调用元数据。Chat 投影快照固定本地化独立提示。录制会话夹具通过公开 headless 与 SDK profile 测试持久纠正；Python SDK 投影使用同一 SDK 协议录制。捕获的会话与协议预期输出保留失败调用结果及完成的第二步骤。自动子进程回放需要宿主允许带管道的子进程；提供方 HTTP 测试需要回环套接字。
