# Agent Note: Qabas 对话标签

Status: implemented

[English](2026-10-02-qabas-conversation-labels.md) | 中文

## 问题

阅读转写的学生看到原始 MCP 名称和参数 JSON，而不是讲座进度。扁平化的 Gemini 额度及模型不可用诊断占据失败请求行，却没有实用提示。

## 决定

ui-tool 拥有通用 `toolTitles` 服务，按线上名称接收纯本地化标题/摘要解析函数。ui-library 通过 effect 提供十六个转写工具标题，并复用任务步骤词典。通用行保留状态、原始输入/输出、展开及 Inspect；键控工具视图仍优先。无效或不完整 JSON 使用原始通用标签。注册和释放发布可观察快照；渲染重新求值当前语言。

ui-chat 将投影后的服务商错误码和文本（包括内嵌 JSON）分类为本地化提示。每日额度优先于每分钟提示；一般账户额度与确认的每日额度区分处理。只有已安排的重试通知承诺自动继续。终止错误和取消的重试不会从 HTTP 429 或 retryDelay 推断重试。投影后的原始文本与错误码保留在详情中。现有 AUTH 投影仍抑制可能携带凭据的文本。

客户端派生工具展示的记录仍是原始 Session 传输、键控渲染分发和私有卡片模型的权威。其禁止第二个展示注册表的规则仅对通用行文本贡献作出限定；没有第二个卡片渲染器或 Host 投影。语言拥有文案的记录仍具权威。两份现有记录均未完全被取代。

## 考虑过的替代方案

**注册十六个完整的键控工具视图。** 业务插件必须重建通用折叠与状态展示，或导入功能组件，违反客户端值导入所有权。纯文本标题贡献将这些机制保留在 ui-tool 中。

**让 ui-tool 知道转写工具名称。** 这会将通用渲染器耦合到一个应用，并将标题与资料库的任务步骤文案分开。

**在 LLM 服务商中分类错误。** 服务商/重试工作独立进行；客户端分类同时处理当前扁平化消息和稳定错误码，不改变重试策略或 Session 事件。

## 后果

业务插件拥有标签，无需共享组件值。实时注册表为通用工具渲染器增加一个框架绑定的可观察源。服务商文本分类保持保守，没有匹配已知类别时使用通用提示。只有调用参数中存在讲座标题时才显示；清单路径不暗示讲座标题。

聚焦测试覆盖标题 effect 生命周期、语言变化、参数有效性、详情及服务商错误格式。所有者本地快照记录展示输出与 Session 事件回放。受保护的 .agents 目录要求将本双语记录交付到 /tmp；现有展示记录的修订必须在该目录可写时应用。
