# Agent Note：转写稿在类似 Obsidian 的编辑器中打开

Status: implemented

[English](2026-10-01-transcript-note-editor.md) | 中文

## 问题

完成的转写稿只能在右侧边栏的文档预览中阅读；它需要对话会话、不能编辑，并把转写稿中的标注块画成普通引用。学生在 Obsidian 中整理笔记，希望转写稿在应用里也以同样的方式打开。

## 决定

新的客户端插件 [ui-note](../../../../packages/client/ui-note/README.zh.md) 注册带标签页的 `note` 主面板，并成为资料库的文件打开方式。它在 CodeMirror 6 中编辑，实时预览完全由 Markdown 语法树上的装饰构成：光标所在行显示 Markdown，其余行渲染标题、强调、列表、标注块、图片和 `[[维基链接]]`。每行按自身文本决定方向，埃及阿拉伯语和英文术语可以正确混排。阅读模式、大纲、搜索和字数统计构成完整功能。

文件通过转写引擎的无会话 `readFile` / `readFileBytes` / `writeFile` 读写。每次保存都携带最后读取的版本，主机拒绝过时的版本；面板随后提供"使用磁盘上的版本"或"保留我的修改"，因为引擎可能会重写正在打开的转写稿。

## 考虑过的替代方案

**扩展文档预览。** 否决：它是受会话约束的只读侧边标签页；编辑和标签页属于不同的界面。

**嵌入完整的 Markdown 所见即所得编辑器。** 否决：它会在保存时改写源文本，而引擎和 Obsidian 都按 Markdown 读取该文件。装饰能让文本保持输入时的原样。

**最后写入者胜出。** 否决：笔记打开期间若发生定稿或图片提取，修改会被静默丢失。

## 后果

无需对话即可阅读和修改转写稿。CodeMirror 成为一个客户端包的依赖。
