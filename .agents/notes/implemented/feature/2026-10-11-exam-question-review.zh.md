# Agent Note: 自动试卷复核与所有者考试年份

Status: implemented

[English](2026-10-11-exam-question-review.md) | 中文

## Problem

OCR 可能将学生标记附加到选项、识别错误的选项标签，并重复印刷题号。缺少官方答案或学生标记含糊，不意味着需要学生检查题目。文件名和扫描日期也可能误示试卷的考试年份。

## Decision

提取保持 OCR 优先：准备好的来源区块交给现有的有据提取器。每份试卷在提取校验后、发布前由 agy 自动复核。复核接收提取的题目及来源文本；图片试卷、无法读取的 PDF 和扫描 PDF（多数页面带有图像）还通过 agy 文件读取器提供渲染页面，因为扫描件的文本层就是 OCR；数字 PDF 依据其文本复核。经过校验的配置限制请求文本、题目数、页数、图像尺寸和耗时。容量失败会拆分题目批次，并保留已完成的复核响应供重试使用。

清理不能添加提取字段或引用的来源区块无法支持的内容词。页面图像读取可以就地更正 OCR 误读，前提是更正后的内容保持至少 75% 的字符相似度；OCR 文本以 `source_stem` 或 `source_options` 保留在出现记录上，只有当该 OCR 文本有来源区块支持时，来源核验才接受这一更正。原始来源引文和区块 id 保持逐字不变，因此清理不会替换来源凭据。答案必须指向现有选项并有来源证据；页面图像证据保留页码及匹配的缓存复核决定。无法确定的答案使用 `uncertain` 或 `no_key`，不要求学生复核。只有无法辨读或截断的来源缺陷保留 `needs_review` 及具体原因。复核失败仍发布已校验的提取结果，标记 `review_status: failed`；成功的复核响应按来源区块哈希、提取题目哈希、复核提示版本及已解析配置缓存。下次输入不变的构建只重试失败复核，不重复提取。

模型可能在一个批次中漏掉部分题目；复核只针对这些题目再请求一次，仍然缺失的题目保留其已校验的提取结果。试卷复核在提取工作线程池上运行，每次写入状态文件都持有同一把锁。

所有者年份存储在 `Questions/.exam-year-overrides.json`，独立于生成的提取和复核缓存。`set_exam_year` 接收原始试卷路径以及 1900 至 2100 的整数、表示无年份题库的 `"bank"`，或 null 以清除覆盖值。选择题库会去掉每次出现的年份，并把来源记为题库，因此讲义把这些题目标为题库题目。索引后处理保留提取年份，并将覆盖值投射到每次题目出现。来源核验根据存储文件验证 `year_source: owner`，而不声称试卷印有该年份。重命名会移动所有者条目；移入回收站保留条目以供恢复。保存或清除年份会刷新现有索引，不调用 agy。

结构化的逐卷进度在既有进度字段之外携带阶段、原始文件名、已知题目数及提取批次计数。API 和编辑适配器提供年份修改及试卷元数据；显示仍由视图负责。[引擎参考](../../../../engine/README.md)负责配置和存储细节；[有界提取](2026-10-10-exam-index-bounded-extraction.zh.md)负责提取调度和发布。

## Alternatives considered

- 将 OCR 优先提取替换为直接图像提取，会改变来源区块的权威，并丢弃可复用的已校验提取批次。
- 要求学生解决缺失答案，会混淆缺少证据与题目损坏，并使索引依赖人工操作。
- 只在生成索引中保存所有者年份，重建时会丢失，且无法独立验证所有者权威。
- agy 复核不可用时令试卷失败，会丢弃仍可使用的已校验提取结果。

## Consequences

自动复核会为输入不变的试卷首次构建增加模型工作。模型可能误读可见标记；文本清理校验和记录的页面证据限制无据修改，但不能证明视觉解读正确。持久的所有者元数据必须独立于缓存失效，清除覆盖值时必须恢复提取年份，而不是推断另一个所有者值。复核失败在文件元数据中可见，并可独立于提取重试。
