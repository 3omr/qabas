# Agent Note：可恢复的资料库移除与固定的 Gemini 设置

Status: implemented

[English](2026-10-03-reversible-removals-and-fixed-library.md) | 中文

## 问题

学生需要移除产出和模块，同时不丢失学习文件。已完成的运行检查点和批处理记录可能让新的转写错误地复用已移除的工作。文件夹选择让 Host 与引擎对资料库位置各有说法。只保存 Gemini 密钥既不会启用 Google 路由，也不会选定第一个聊天模型。

## 决策

Python 引擎在模块本地的回收站清单中负责可恢复的文件与转写移除。一个转写条目保留所选产出、最终图片与 Anki 产物、被移除的 Index 行，以及匹配的运行检查点目录；匹配的批处理记录被清除。移除草稿时还会保留分段草稿和草稿检查元数据，使已移除的文本无法从已完成的阶段重建。清除整个匹配的运行，可以避免保留引用已移除工作的已完成依赖；无关讲座不受影响。恢复前会拒绝已被占用的路径，并保留之后无关的 Index 与批处理编辑。

整个模块通过同一文件系统内的重命名移入资料库的模块回收站；其笔记本和 NotebookLM 来源保持不变。恢复模块时，若 id 已被重新使用则拒绝。回收站不会自动过期。隐藏的讲座共用回收站清单，并通过录音可见性恢复，不会重建定义。

模块之外的准入闸门与操作系统持有的活动租约保护启动器和 MCP 操作。移除会探测现有的模块、讲座、批处理与 Index 锁，同时排除新准入的引擎工作。这一保护会保守地拒绝整个活动模块。它无法识别两次引擎调用之间空闲的聊天；浏览器任务状态不是 Host 的权威来源。

Host 与 Python 各自拥有一个默认路径函数：开发者覆盖 `TRANSCRIBER_WORKSPACE`，否则为操作系统主目录加 `Qabas Library`。首次使用会创建 `modules/`。保存的学生文件夹选择和 cwd 不再决定资料库。会话工作区保留其独立策略。

保存 Gemini 密钥时，先存储凭据，再在 `llm-pi-ai` 中为缺失的 Google 路由写入空配置。发现流程选择最新的主力 Flash 模型，仅在部署尚无默认值时保存。删除凭据会保留路由和默认值。现有的 Google 额度回退仍由提供方解析出的默认值启用。客户端数据 API 返回明确的编辑结果；UI 控件和刷新由其使用方负责。

## 考虑过的替代方案

**永久删除。** 学生的移除操作必须可恢复，包括产出和可续跑的状态。

**以浏览器任务记录作为移除保护。** 这些记录只属于一个客户端，无法排除另一个引擎进程。

**保留已完成的检查点阶段。** 已完成的阶段文件和分段草稿可以在不重新运行所请求转写的情况下重建已移除的文本。

**保存学生的文件夹选择。** 所有者在桌面和 Python 入口处固定资料库位置；保存的指针会造成相互竞争的权威来源。

**连同密钥删除 Google 路由。** 之后的新密钥必须无需重新选择路由或重置现有默认值即可工作。

## 影响

在已编辑元数据未变时，恢复会保留原始字节，并合并之后无关的 Index 与批处理编辑。目标路径或进度冲突需要学生处理所指明的路径。引擎测试使用临时目录，覆盖锁拒绝、回滚、阶段、回收站排序和真实的 MCP 分发。Host 与客户端测试覆盖线路校验、数据映射、默认路径一致性和条件式 Gemini 配置。

本决策部分取代了无需会话的转写资料库工作区笔记中的文件夹选择决策；该笔记的清单与文件访问策略保持独立。讲座管理、讲座可见性和每日额度回退决策保留各自独立的职责。
