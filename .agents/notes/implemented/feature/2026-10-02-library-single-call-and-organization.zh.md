# Agent Note: Qabas 整库快照与引擎整理

Status: implemented

[English](2026-10-02-library-single-call-and-organization.md) | 中文

## 问题

包含多个模块的资料库在显示进度前，要为每个模块启动 Python 进程并读取笔记本清单。重新加载浏览器会重复等待。已审阅的讲座整理及考试索引需要由学生触发、无需聊天 Session 的引擎调用。

## 决策

[引擎 Remote](../../../../packages/api/transcriber-engine/README.zh.md)一次读取整个资料库，验证每个模块清单或独立错误，并保留题目索引状态及笔记本清单时间戳。[资料库](../../../../packages/client/ui-library/README.zh.md)从按引擎工作区路径命名的版本化浏览器存储恢复上次连接的工作区，并标记为刷新中，直到新的缓存清单结果到达。打开已加载内容不会额外读取；显式刷新请求新的远端清单。存储无效或被拒绝不会阻止引擎。整库刷新期间启动的模块读取保留更新后的内容。

提案、应用整理及考试索引均为可选编辑回调，分别由各自已挂载的 Remote 方法启用。提案 id 在审阅时成为已有 id，在学生应用定义时成为写入 id。应用整理传递明确确认。可配置的操作截止时间会终止缓慢 MCP 调用；考试索引保留 launcher 文本。上传仅使对应模块的笔记本存在状态失效，已完成的索引构建更新该模块的索引状态。

Agy 索引会将文件名标明的题库保留为题库，即使文件只包含一个考试年份。只有原始字节和引用单元仍能支持题目的记录才会保留；来源章节或证据支持的年份才会保留。合并题干必须匹配已验证的记录，除非已记录的人工修复引用了该记录；第一页标记前的文本会保留行定位。

开始讲座即授权引擎自动上传。如果 `begin_lecture` 返回 `needs_upload`，preset 用一句话指出失败文件及原因后停止，不提供替代转写路径。agy writer 响应保留单次 writer 工具指令。只有已完成的引擎 JSON 含非空字符串数组时，任务进度才报告录音已上传。doctor 保留可选 agy 条目，并将其 null 安装命令视为手动操作，不执行它。

本决策扩展[无会话工作区](2026-10-01-transcriber-library-workspace.zh.md)与[讲座管理](2026-10-02-lecture-manager-wiring.zh.md)决策；路径包含、文件接收、转写写入及取消义务继续有效。两个记录均未被完全取代。其目录在此工作区中为只读，因此本语言对使用已授权的临时位置。

[试卷原件准备决策](2026-10-06-exam-file-preparation.zh.md)通过逐份提取和原件字节失效扩展索引构建；清单与组织决策仍有效。

[托管资料库决策](2026-10-07-managed-library-workspace.zh.md)固定资料库根目录，并增加聊天存储和不可变工作区展示；库存和组织仍由本决策拥有。

## 考虑过的替代方案

**启动时逐模块调用。** 这会成倍增加进程启动与笔记本清单成本。已挂载 Remote 缺少整库方法时保留该路径。

**每次导航读取新清单。** 缓存清单能立即提供进度；显式刷新及改变笔记本的操作请求新的存在状态。

**将考试索引输出解析为 JSON。** 引擎 launcher 打印可读摘要及目标路径。保留文本避免虚构结果字段，并让引擎失败继续作为类型化拒绝。

## 后果

在引擎识别当前工作区前，浏览器可能短暂显示上次连接的工作区；新结果会替换全部模块成员及内容。缓存包含元数据与文件路径，不包含转写正文或凭据，也不成为引擎权威。模块重新加载使用当前试卷状态与数量；旧版 Remote 缺少这些字段时，保留上次整库读取的数量。假 MCP 测试覆盖验证、已确认写入、截止时间及 launcher 文本；服务与适配器测试覆盖单次加载、回退、缓存显示、存储失败及模块失效。记录的 Session 事件固定上传任务进度。真实 agy、NotebookLM 与考试 OCR 仍属于外部集成检查。
