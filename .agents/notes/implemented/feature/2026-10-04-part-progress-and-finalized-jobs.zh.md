# Agent Note: 分段进度与已定稿讲座任务的结果

Status: implemented

[English](2026-10-04-part-progress-and-finalized-jobs.md) | 中文

## 问题

分段写作 MCP 调用的每一段持续数分钟，而按工具计数的进度条只在调用返回时前进。提供方拒绝结尾摘要时，成功定稿的讲座也可能被误报为失败。若只有部分子问题属于已教授范围，考核生成还可能丢弃相关的有来源临床病例。

## 决策

MCP 进度是按根调用与运行中调用 id 关联的信息性 Session 数据。SDK 负责请求进度令牌与回调清理。引擎的每一段报告开始与成功暂存，包括显式替换；失败不会声称写作完成。Session 追加可以持久化可忽略标记，让旧读取方省略进度而不改变模型重建。Chat 负责实时与回放投影，LibraryJobs 消费该公共投影。

讲座任务拥有一个 transcriber 会话。该会话中任何成功的 finalize 都记录持久化目标里程碑；之后的模型错误成为任务备注，终态结果保持完成。这部分取代后台资料库任务记录中的最后工具完成条件；其启动、共享事件源、取消和问题归属规则仍然适用。模块级任务保留正常回合结束语义。

Gemini Developer API 请求通过经校验的提供方阈值显式配置四项可调整过滤器，默认为 BLOCK_NONE。由于密钥与项目限制不同，Vertex 保留提供方默认设置。Google 核心保护保持启用，禁止内容拒绝仍由 blocked 失败类型提供可操作诊断。请求格式测试不证明特定密钥层级的实时接受情况。

有来源的患者场景属于 Clinical Cases。只要至少一个子问题已教授，有来源病例就仍然相关；只剪除未教授子问题，并对保留问题重新编号。有来源病例排在 IMP 补充之前。校验器执行可识别患者场景的分区、有来源病例先于 IMP 的顺序与保留子问题的连续编号；语义范围与遗漏病例检测由证据审查负责。

## 考虑过的替代方案

**只计数已完成工具调用。** 这无法显示单次长写作调用内部的工作。

**将进度作为模型输入。** 进度描述展示，将它加入模型上下文会增加无关 token 并改变结尾请求。

**要求结尾摘要成功。** 定稿器已经提交讲座并更新索引，之后的提供方失败不能撤销该结果。

**剪除部分相关的有来源病例或用生成病例替代。** 这会丢失已教授的历年试题材料，并掩盖来源证据与生成练习之间的区别。

## 后果

托盘可以消费进度计数与原始消息，独立决定展示设计。进度在调用结果时停止。持久化目标里程碑在重新加载后仍保留，即使当前历史窗口不包含定稿器。可调整 Gemini 过滤器不能保证医学文本被接受，没有来源审查的提示词规则也无法证明讲座语义覆盖。

## 验证

临时引擎 fixture 覆盖进度令牌有无、成功分段、显式修复、失败写作与提示词规则。完整转写与编辑质量测试拒绝场景错放及有来源病例排在 IMP 之后。假 MCP 传输覆盖已安装 SDK 与持久化 Session 检查点。真实客户端插件投影原生及嵌套进度，在结果时清除进度，并使已定稿任务在被拦截回合之后仍保持完成。已安装 Google SDK 测试观察发出请求中的 safetySettings 字段。
