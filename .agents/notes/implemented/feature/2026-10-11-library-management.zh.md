# Agent Note: 讲座和试卷管理页面

Status: implemented

[English](2026-10-11-library-management.md) | 中文

## 问题

所有者认为讲座和试卷管理很难用。模块的讲座进度条紧贴在题库横幅下方，看起来像是索引进度。讲座页面重复显示该横幅，操作分散，拖放区域在所有卡片之后，每个文件都带一个没有标注、点了立即生效的 "×"。试卷页面把已读取但未索引的试卷标成 "جاهز"，构建题库时只显示静态文字，也没有批量操作。首次加载时显示空白区域，刷新时内容会被替换。

## 决定

模块概览拥有一个带标签的转写部分（"التفريغ: N من M جاهزة"）和它自己的进度条。题库卡片只出现在概览和试卷页面，并在索引构建运行时显示实时进度。讲座管理页面不再显示该横幅。

两个管理页面都有一个吸顶工具栏，只有一个主要操作，整个页面都接受拖入的文件，只有外部文件拖动时才显示覆盖层。讲座以紧凑的整行显示（标题、录音和资料数量、所有权标记、转写状态），展开后显示文件。行菜单提供重命名（行内；Enter 保存，Escape 取消）、编辑和移除讲座。移除使用现有的隐藏/恢复语义，其对话框说明文件和转写都会保留。每个文件有两个带标签的操作："شيل من المحاضرة" 把文件留在模块中，"ودّيه السلة" 在确认后把文件移到回收站，确认中说明可以恢复。删除适配器保留引擎现在返回的回收站条目 id，因此只有在存在恢复标识时，提示中才会提供撤销。编辑对话框包含标题、有序的录音（拖动或"更早/更晚"按钮）、资料以及未分配文件的选择器。

试卷行用图标和文字显示不同的状态：未读取、读取中、已读取但未索引、已索引并显示题目数和需复核数、失败并显示原因和重试。引擎给出的试卷说明显示在试卷下方；固定的年份不一致说明会被本地化。行支持选择和批量移到回收站。一个流式的试卷索引 Remote 把引擎真实的 MCP 进度（已完成和总试卷数、当前试卷、部分和拆分）转发给一个进度展示组件，并显示已用时间和停止按钮；完成方法仍保留给现有调用方。

上传时逐个列出文件，测量本地准备过程，并在引擎确认导入之前显示不确定的保存阶段；不会为单次请求的传输编造百分比。一个 Skeleton 基础组件在首次加载时预留行的布局，后台刷新保留当前内容，每次写入只在它自己的行上显示等待状态。菜单会把焦点移到其选项上，并在按 Escape 时把焦点还回去；对话框会限制焦点。

## 考虑过的替代方案

**重新设计现有卡片的样式。** 仅靠 CSS 无法加入撤销所需的标识、流式进度或逐行的等待状态。

**编造上传百分比。** 导入 Remote 只发送一次请求，没有传输检查点，所以由计时器驱动的进度条会声称发生了并未发生的进度。

**现在就单独做科目模型。** 讲座列表渲染分组区块，以便之后的科目分组可以复用，但科目的持久化是另一项改动。

## 后果

学生在控件生效之前就能看到它会改变什么，可以撤销移到回收站的操作，也可以跟踪并停止索引构建。引擎的 `remove_file` 结果增加了回收站条目 id。英语和阿拉伯语词典包含所有新字符串；由所有者维护的快照固定了两种语言。这些行已在实时预览中按应用面板宽度检查，包括展开的文件、回收站确认和撤销、编辑对话框以及实时索引进度。
