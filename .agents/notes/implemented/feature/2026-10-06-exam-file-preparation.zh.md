# Agent Note: 试卷原件与逐文件准备

Status: implemented

[English](2026-10-06-exam-file-preparation.md) | 中文

## Problem

试卷上传后，在 PDF 提取或 OCR 前就进入只读取文本的索引。同名文件会停止整批导入，已有试卷的模块会失去添加入口。原件被替换或移除后，旧提取文本仍可能存在，并提供错误的考试证据。

## Decision

[资料库](../../../../packages/client/ui-library/README.zh.md)在独立路由上打开试卷管理，并提供返回模块的导航。原件卡片区分提取就绪和当前索引归属，并显示解析题目数量。上传保留原件，明确处理同名文件，并在建立索引前逐份准备试卷。相同原件哈希会跳过重复导入；其他选项是替换、保留不同名称的副本和跳过。单个文件失败保留诊断，不停止后续导入。取消会停止排队的工作；已经写入的文件保留，供重试使用。

[引擎](../../../../engine/README.md)在来源目录外记录原件哈希和生成的文本文件名。派生文本在 `.txt` 后缀前保留完整原件名，避免不同格式试卷之间的冲突。准备过程复用既有转换和 OCR 实现；本地 OCR 失败后，该实现可以通过 agy 识读图像。DOCX 段落与表格顺序保留，供题目解析使用。生成的文本参与索引与来源核验，但不显示在学生的原件清单中。替换文件、重命名和移入回收站使所属文本与索引失效。外部删除只清理已记录的派生文本。失效的索引保留未改变试卷的人工修复，移除改变试卷的题目出处，并在重建前保持过期。发布索引时持有模块编辑锁，并再次检查原件是否就绪。比较原件字节可避免对已改变的试卷误用缓存就绪状态。

全资料库、无需 Session 的工作区和可恢复移除决策仍然有效。本决策扩展[全资料库记录](2026-10-02-library-single-call-and-organization.zh.md)，不替代其清单、组织或缓存归属。阿拉伯语字典包含试卷控件与其他功能命名空间；外部扩展仍可使用英语回退。各语言的产品文案保留相同的插值字段。

## Alternatives considered

**复制 PDF 后立即建立索引。** 索引只读取文本文件，无法推断缺失的准备步骤。

**隐式覆盖同名文件。** 新选择可能是不同试卷，也可能是意外重复；原件哈希和明确选项保留这种区分。

**只用文件名主干命名提取结果。** 同主干的 PDF 与 DOCX 试卷相互冲突，也会与学生编写的文本冲突。

**运行全模块来源同步。** 准备试卷不授权向 NotebookLM 上传无关讲座录音或参考资料。

## Consequences

不可读的必需试卷阻止索引完成，但成功的导入与提取结果可以复用。既有本地文件无需重新导入即可显示。删除所属文件前先验证缓存元数据；损坏状态会明确报错。转换与 OCR 仍依赖已安装工具，agy 修复可能消耗模型额度。Windows 原生安装与实际认证识读需要在目标机器验收。Host 与组件测试覆盖同名选项、部分失败、取消和重试；Python 测试验证原件保留、DOCX 顺序、真实 PDF 读取与移除失效。英语和阿拉伯语展示快照及字典字段检查覆盖产品文案。
