# Agent Note: 试卷原件与逐文件准备

Status: implemented

[English](2026-10-06-exam-file-preparation.md) | 中文

## Problem

试卷上传后，在 PDF 提取或 OCR 前就进入只读取文本的索引。同名文件会停止整批导入，已有试卷的模块会失去添加入口。原件被替换或移除后，旧提取文本仍可能存在，并提供错误的考试证据。

## Decision

[资料库](../../../../packages/client/ui-library/README.zh.md)在独立路由上打开试卷管理，并提供返回模块的导航。原件卡片区分提取就绪和当前索引归属，并显示已提取题目出现次数及需复核数。已索引卡片可打开该文件的可搜索分页视图，显示原文、选项、试卷答案与解释、年份和来源位置。上传保留原件，明确处理同名文件，并在建立索引前逐份准备试卷。相同原件哈希会跳过重复导入；其他选项是替换、保留不同名称的副本和跳过。单个文件失败保留诊断，不停止后续导入。取消会停止排队的工作；已完成的文件写入和通过模型校验的批次保留，供重试使用。

[引擎](../../../../engine/README.md)在来源目录外记录原件哈希和生成的文本文件名。派生文本在 `.txt` 后缀前保留完整原件名，避免不同格式试卷之间的冲突。准备过程复用既有转换和 OCR 实现；本地 OCR 失败后，该实现可以通过 agy 识读图像。建立索引时，agy 按原件各区块提取题目，并校验输入覆盖、来源措辞、答案证据和年份。XLSX 行及 DOCX 段落或表格行保留直接位置；其他支持格式使用已准备的页面或行文本。按原件哈希保存的结果写入 `.exam-index-state.json`，取消或失败后可继续使用。带版本号的索引会跨试卷合并重复题目，同时保留每个文件的全部题目出现次数、原文和位置。来源核验会重新读取原件区块，并在检查原件与派生文本哈希后才采用题目。生成的文本参与来源核验，但不显示在学生的原件清单中。替换文件、重命名和移入回收站使所属文本与索引失效。外部删除只清理已记录的派生文本。失效索引在所有现有原件重建前保持过期。旧版 schema-1 索引不含来源指纹，因此其中的人工修复不会沿用；后续修复仅在原件与派生文本指纹均未变化时沿用。发布索引时持有模块编辑锁，并再次检查原件就绪状态与哈希。比较原件字节可避免对已改变的试卷误用缓存就绪状态。

全资料库、无需 Session 的工作区和可恢复移除决策仍然有效。本决策扩展[全资料库记录](2026-10-02-library-single-call-and-organization.zh.md)，不替代其清单、组织或缓存归属。阿拉伯语字典包含试卷控件与其他功能命名空间；外部扩展仍可使用英语回退。各语言的产品文案保留相同的插值字段。

## Alternatives considered

**复制 PDF 后立即建立索引。** 索引只读取文本文件，无法推断缺失的准备步骤。

**只使用正则解析器提取题目。** 它会丢失工作簿列，也会漏掉不符合其行模式的题目；agy 会返回带原件区块和位置的结构化题目。

**在讲座查询里返回所有题目。** 该查询为单节讲座排序，最多返回 50 项；文件审核需要全部出现记录，因此使用独立的搜索与分页请求。

**隐式覆盖同名文件。** 新选择可能是不同试卷，也可能是意外重复；原件哈希和明确选项保留这种区分。

**只用文件名主干命名提取结果。** 同主干的 PDF 与 DOCX 试卷相互冲突，也会与学生编写的文本冲突。

**运行全模块来源同步。** 准备试卷不授权向 NotebookLM 上传无关讲座录音或参考资料。

## Consequences

不可读或未完整索引的必需试卷会阻止索引完成，但成功的导入、准备结果和 agy 批次可以复用。旧版正则索引会保持过期，直到 agy 重建。既有本地文件无需重新导入即可显示。删除所属文件前先验证缓存元数据；损坏状态会明确报错。转换与 OCR 仍依赖已安装工具，agy 提取可能消耗模型额度。Windows 原生安装与实际认证识读需要在目标机器验收。Host 与组件测试覆盖同名选项、逐文件分页、部分失败、取消和重试；Python 测试验证来源一致的提取、可恢复批次、原件保留、DOCX 顺序、真实 PDF 读取与移除失效。英语和阿拉伯语展示及字典字段检查覆盖产品文案。
