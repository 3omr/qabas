# Agent Note: 可恢复的讲座可见性与 Gemini 密钥认证检查

Status: implemented

[English](2026-10-03-lecture-visibility-and-key-checks.md) | 中文

## Problem

移除手动讲座定义后，其录音通过自动分组重新出现。自动单元没有移除操作。现有转写稿也可能作为孤立行重新出现。Gemini 目录发现使用内置模型列表，无法确认已保存的密钥是否有效。提供方耗尽消息可能包含模型不可用的措辞，即使每个模型的每日额度都已用尽。

## Decision

引擎在 module.json 中持有可恢复的可见性。hidden_recordings 包含相对于 Lecture/ 的安全名称。hide_lecture 在完整的本地及已缓存 NotebookLM 清单中解析手动 id 或标题，并在一次加锁的原子写入中隐藏全部录音及移除定义。restore_recordings 移除选定名称，不重建定义。恢复前，定义或整理写入不能认领隐藏录音；文件清单继续标识它们，未分配来源则排除它们。部分恢复的分组只包含可见录音。

hidden_transcripts 为失去手动定义的自定义标题现有旧式转写稿保留录音关联。录音来源记录、保存的关联及完全隐藏的单元共同抑制孤立转写稿行。源文件、NotebookLM 来源与转写稿保持不变。Host 与 Client 数据 API 通过现有注册表进程运行器提供隐藏及恢复；调用方在成功后重新加载相应模块。

credentials Remote 在每次显式检查时于 Host 解析 GEMINI_API_KEY，仅通过固定 Gemini 模型目录请求的 x-goog-api-key 请求头发送它，并只返回安全状态。配置的默认五秒截止时间包含正文读取；取消会传递到 fetch。不返回重定向、密钥值、提供方正文或异常文本。配额结果在响应提供证据时标识每日或每分钟限制，否则报告 unknown。目录认证不能证明生成额度或模型访问权限。

资料库先于通用不可用消息识别显式每日重置、DAILY_QUOTA_EXHAUSTED 及模型额度耗尽诊断。其重置辅助函数返回考虑夏令时变化的下一个太平洋时间午夜。Accounts 与资料库辅助函数共用预期重置样例，同时保留为不同值，因为本次修改不增加依赖。UI 控件及渲染仍由调用方持有。

## Alternatives considered

**删除录音或 NotebookLM 来源。** 将讲座移出视图是可恢复的整理操作，不是销毁学生数据或远端来源。

**仅存储隐藏讲座标题。** 自动分组可能改变标题，手动定义也可能被移除。录音身份提供持久的可见性依据；旧式转写稿关联仅补足现有文件所缺少的来源记录。

**用模型发现验证密钥。** 内置目录不需要认证请求，无法验证凭据。credentials Remote 已持有已存密钥解析，Accounts 客户端也已调用它，因此无需与 Python 或提供方发现机制耦合。

**生成文本测试密钥。** 目录请求无需消耗生成请求即可验证认证。它有意不保证剩余生成额度。

**通过新增包依赖共享配额代码。** 两个 UI 包没有适合此函数的共同工具依赖。少量重复计算与共同样例满足依赖约束，且生产代码无需导入另一 UI 插件的值。

## Consequences

[讲座管理器](2026-10-02-lecture-manager-wiring.zh.md)、[资料库清单](2026-10-02-library-single-call-and-organization.zh.md)、[每日模型回退](2026-10-02-daily-quota-model-fallback.zh.md)与[对话标签](2026-10-02-qabas-conversation-labels.zh.md)决策保留各自的归属及备选方案。本说明扩展其数据操作及失败分类；没有任何说明被完全取代。

恢复录音可能暴露自动分组或孤立转写稿，因为它不重建自定义定义。隐藏转写稿关联是附加的模块元数据，并跟随录音重命名及移除。目录检查成功后，生成仍可能失败；真实 Google 验证仍是需要密钥及网络连接的集成检查。确定性测试使用模拟 HTTP 响应，观察精确安全状态、当前凭据解析、截止时间及取消。

Python 测试覆盖本地及仅远端单元、部分恢复、旧式及带来源记录的转写稿、定义归属拒绝、不安全的持久化元数据、原子写入失败及直接 CLI/MCP 操作。Host 与客户端测试覆盖 wire 准入、结果验证、隐藏标志、回调、安全密钥结果、提供方失败及太平洋时间重置日期。显式数据调用无需 Session 或模型请求。
