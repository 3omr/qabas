# Agent Note: 确定性讲座流水线

Status: implemented

[English](2026-10-04-deterministic-lecture-pipeline.md) | 中文

## Problem

讲座任务消耗学生的对话模型配额来协调固定流程，而实际写作已经由 Antigravity 完成。模型失败可能中断讲座、重新提交过大的草稿或询问无关文件。

## Decision

[引擎](../../../../engine/README.md#deterministic-lecture-jobs) 为 transcribe、redo 和 continue 提供一个需要确认的 MCP 流程。它组合现有的讲座准备、上传、逐字稿、主题规划、插图、写作、审核、验证、来源核验及最终提交逻辑。最终提交负责转写文件和 Index.md。讲座按钮授权这一次运行；模块级来源同步和无关上传仍是单独操作。

[Remote](../../../../packages/api/transcriber-engine/README.zh.md#lecture-pipeline) 无需 Session 即流式提供步骤和分段进度。取消先发送所属 MCP 请求的取消消息，再终止进程，清理等待进程退出。引擎取消保留已完成的分段。Continue 使用保留的分段或已保存草稿；redo 在替换成功之前保留最终转写。

恢复保持普通审核、内容完整性及来源检查启用。确定性清理之后是 agy 定向重写和更小的来源片段；暂时性提供方错误及每分钟限制通过可取消的退避重试。失败输入会刷新，可选插图可在讲座 manifest 中标记省略。主题布局不可用时仍保留基于录音的修复文本。具体诊断和恢复元数据可以交给有界对话修复，绝不发送完整草稿。对话无法最终提交时，引擎挽救归档原文，裁去无法核验的题目及可选支持内容，验证最佳保留转写。说明修复耗尽后，完整医生逐字稿仍是回退内容。

[资料库运行器](../../../../packages/client/ui-library/README.zh.md) 持久化任务标识、恢复 manifest、修复期限、进度和备注。修复显示为运行，验证后的完成显示为 done，仅网络断开、每日或账户配额耗尽、登录过期及录音缺失以简明原因显示为 stopped。每分钟限制及超时仍可修复。报告的重置时间本地化显示；Gemini API 每日重置采用太平洋时间午夜，未知账户重置仍明确说明未知。Remote 缺失时使用 transcriber 对话。对话修复有时间限制，并须停止写入后才能挽救；仍可打开对话。中断的无会话任务恢复为已停止，Continue 复用引擎文件。

本决策部分取代[后台任务](../feature/2026-10-01-library-background-jobs.zh.md)和[已完成任务](../feature/2026-10-04-part-progress-and-finalized-jobs.zh.md)中每节讲座对应一个 Session 的假设；它们关于任务准入、对话观察和完成里程碑的依据仍有效。[有界修复决策](../bug-fix/2026-10-04-bounded-review-repair.zh.md)仍负责定义保留分段及内联审核限制。这些笔记均未被完全取代。

## Alternatives considered

**用更便宜的对话模型协调。** 配额、截断和自主停止仍会限制固定流程。

**重新实现每个步骤。** 独立实现会偏离 preset 现有的来源、审核及最终提交规则。

**拒绝后重新生成完整草稿。** 这会为未受影响的文本消耗 writer 调用，并丢弃有用的暂存工作。

## Consequences

普通讲座任务需要 agy 和 NotebookLM，但不需要对话 API 请求。引擎恢复默认六轮、两秒初始退避和三小时预算；对话修复默认五分钟。部署配置负责这些限制。经验证的挽救不会默默更改题目来源标记或丢弃医生文本。引擎不可用、存储不可写或必需来源不可用可能阻止任何有效提交；完成备注说明保留工作可通过 Continue 继续，不宣称最终提交里程碑。浏览器重新加载会中断所属请求，不会默默启动新一轮运行。

临时模块测试使用假的 nlm 和 agy 及真实引擎验证和最终提交，覆盖暂时性重试、确定性修复、小片段写作、强制裁剪、仅学生能解决的中断、取消和 Continue。Remote 与客户端测试覆盖流式进度、结果、中止、对话交接及挽救。这些测试不复制或写入真实学生数据。
