# Agent Note: Qabas 桌面发布保持 Alpha

Status: implemented

[English](2026-10-06-qabas-alpha-releases.md) | 中文

## 问题

桌面发布程序仅在构建版本包含后缀时标为预发布版。因此，无后缀的构建可能在 Qabas 仍处于开发阶段时显示为稳定版本。

## 决策

应用稳定前，每个桌面版本均以 Qabas Alpha 为标题，并使用 GitHub 预发布标记。构建版本一致性和目标原生验证仍为必需。现有安装程序的版本标识保留；发布分类不改变其编译后的元数据。

## 考虑过的替代方案

**从版本后缀推断稳定性。** 拒绝，因为构建编号不证明应用稳定性。

**只更改当前版本的标题。** 拒绝，因为下次自动发布会恢复依赖版本号的分类。

## 后果

当前及未来的桌面发布页面标识 Alpha 构建。发布测试用独立文件和记录调用的 GitHub CLI 替身执行真实 shell 步骤，覆盖有后缀及无后缀的版本。稳定发布需要显式更改此策略。
