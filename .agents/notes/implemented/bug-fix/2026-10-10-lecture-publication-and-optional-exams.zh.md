# Agent Note: 讲座发布与可选的考试证据

Status: implemented

[English](2026-10-10-lecture-publication-and-optional-exams.md) | 中文

## 问题

一次失败的考试刷新会在每一轮讲座修复中重新开始。抢救可能把五个标题组成的骨架误当成转写稿，即使根本没有录音内容。生成的考试文本和遗留的同名文本会在准备和上传计划中重复原始试卷。模块级的书籍可能变成某一讲的幻灯片，并把封面强行放进讲解中。

## 决定

[讲座流程](../../../../engine/README.md#deterministic-lecture-jobs)在修复之前只刷新一次考试证据。失败或部分成功的刷新会保留未变化且有试卷支撑的出现记录，并添加一条英文说明，列出缺少往年考试年份的试卷。讲座题目查找独立验证每个出现记录，而不要求模块全部覆盖。显式的考试管理查找保留其对过期索引的拒绝。

抢救和 MCP 定稿要求：在去掉标题、引用块、图片链接和 HTML 注释之后，Chronological Guide 中有含字母的讲述内容；在去掉标题和引用块之后，保存的逐字基线中有含字母的讲话。现有的完整文档、覆盖率、编辑和出处检查仍然是必需的。没有经过验证的材料时，其他部分可以为空。完整保存的医生原话仍是有效的回退；没有医生原话不算成功的转写。

没有可发布内容的恢复会返回 `failed`，在 `reason` 和 `findings` 中保留第一次失败，并在 `step` 中记录其工具；`salvage_error` 报告独立的恢复失败。可用的 `resume` 元数据指明保留的模块/清单状态。发布不会写入转写稿，也不会修改 Index.md。Remote 会验证这个结果，资料库保存原始原因，保持 `goalReached` 为 false，并以失败结束，不做自动传输重试。

清单和自动清单会排除由准备流程拥有的派生考试名称、配对的同名文本、隐藏文件和 JSON 产物。一份原始试卷只提供一个评估候选。自动选择的幻灯片排除通用资料和其他讲座的资料。复用时会移除缓存中指向通用资料的幻灯片分配。没有幻灯片的讲座按医生录音的顺序进行，不要求图片；标为 “picture slide; no machine-readable description” 的中性页面不要求讲解中的链接。

这部分替代了 [有界定稿](2026-10-04-finish-always.zh.md) 和 [确定性的讲座恢复](../architecture/2026-10-04-deterministic-lecture-pipeline.zh.md) 中关于终止回复的限制。它们关于保留已验证评估、修复预算、取消和发布所有权的规定仍然适用。[考试失败隔离](2026-10-10-exam-index-failure-isolation.zh.md) 和 [同名文本所有权](2026-10-10-automatic-exam-reading-sidecars.zh.md) 保留各自独立的理由；索引提取和 OCR 没有改变。这些记录保持有效，因为它们的所有权和出处规则仍然指导今后的修改。

## 考虑过的替代方案

**在讲座修复期间重试考试索引。** 索引失败与讲座写作无关，重复执行代价高昂的工作也修复不了录音内容。

**恢复耗尽后发布骨架。** 一个已完成的文件和索引条目并不能证明获得或验证了任何讲座内容。

**要求每个部分都有编造的内容。** 没有有据题目时，评估部分为空是合理的；录音讲解内容才是必需的最低要求。

**把通用书籍作为幻灯片回退。** 模块参考资料不能确定某一讲特有的幻灯片顺序或图片。中性页面标签不提供放置依据。

## 后果

完成的讲座可能缺少部分试卷的往年考试年份，并会明确报告这些缺失。失败的运行保留可恢复的产物，需要点击继续，而不会产生虚假的完成节点。这个最低要求是结构和来源存在性的验证，并不是新的语义证明来保证每个生成的句子都与讲话一致；现有的覆盖率和出处检查继续提供它们的保证。测试使用临时模块和假的提供方，不涉及真实 agy、NotebookLM、网络请求或学生资料库。
