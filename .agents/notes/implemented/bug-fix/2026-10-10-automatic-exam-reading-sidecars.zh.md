# Agent Note: 自动读取考试试卷与遗留的同名文本

Status: implemented

[English](2026-10-10-automatic-exam-reading-sidecars.md) | 中文

## 问题

扫描试卷可能带有损坏的可搜索文本层，其中包含格式标记、孤立的阿拉伯字母和破碎的词元。永久性的修复失败标记使得工具或源文件字节变化后也无法恢复。遗留的同名文本文件会重复计算试卷数量并重复送入模型。学生需要的是自动准备，而不是让他们去识别或修复扫描件的说明。

## 决定

PDF 准备在稀疏文本和损坏字符之外，还会测量文字噪声。清单条目可配置 `ocr_format_control_limit` 和 `ocr_script_noise_limit`；考试请求从引擎配置继承这些设置以及 `ocr_language`。每个不成功的请求允许一次本地重试，使用从已安装程序中探测到的旋转和纠偏选项。失败标记仅作为诊断产物保留，不能否决之后的请求。源文件和语言仍是产物缓存键的一部分。

缺少读取所需的可执行文件或语言数据时，使用 `ocr_tool_missing`，并在可选的 `tools` 中给出安装器名称。API schema 和 Client 结果保留这些字段。桌面端的考试视图和模块横幅共用一个准备辅助函数，以及设置队列所用的安装器消费者。它们按顺序安装报告的工具，对受影响的试卷重试一次，并用工具名本地化安装失败信息。Linux 和 macOS 的 Tesseract 安装计划包含多语言数据。面向学生的文案描述的是自动读取。

现有的考试文本状态以大小写不敏感的方式，把同一目录下同名主干的文档和文本文件配对，记录在可选的 `sidecar` 中。仅配对的记录使用 `prepared: false`，不能授权覆盖学生那些看起来像生成物的文件。清单和来源选择共用配对辅助函数。文档读取成功时以其文本为准；文档读取失败后，可用的同名文本提供派生副本并标记 `fallback: true`。之后的显式请求会重试文档读取。原始文件和同名文本保留其字节。旧记录仍然有效，按题和按试卷的失败隔离保持不变。发布在验证清单时复用其已持有的模块注册锁。

## 考虑过的替代方案

**信任任何非空文本层。** 损坏的双语提取可能含有足够多的字母而通过稀疏文本检查，却提供不可用的证据。

**要求学生先做准备步骤。** 扫描识别和缺失工具的恢复属于自动的考试准备。

**保留永久的负面缓存。** 一次失败不能说明之后的源字节、语言、工具或显式请求也会失败。

**删除同名文本或两者都索引。** 删除会丢失学生数据；两者都索引会把一份试卷算两次。回退保留了有用的遗留文本，同时不优先于新的读取结果。

## 后果

显式的失败请求可能执行两次本地识别和有界的页面图像修复。启发式阈值可能误判少见的试卷，因此保持可配置。自动安装沿用现有的桌面安装器，可能因平台策略而失败；界面保留本地化的、指明工具的诊断信息。合成的 Python 和 Client 测试覆盖了有噪声和干净的文本层、重试、结构化失败、清单、回退优先级、所有权、受支持的参数、安装和本地化，不涉及真实 agy、网络请求、系统安装或学生数据。
