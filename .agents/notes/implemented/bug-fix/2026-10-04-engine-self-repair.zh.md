# Agent Note: 引擎的确定性自我修复

Status: implemented

[English](2026-10-04-engine-self-repair.md) | 中文

## Problem

如果解析拒绝和证据明确的来源标记不匹配仍需模型处理，无人值守的讲课任务就可能耗尽聊天模型的配额。缓存的主题解析拒绝隐藏被拒绝的回答，并保留按学生群体重复的章节。病例情景的改写还可能让词汇匹配遗漏真实的带年份考试记录。

## Decision

[引擎](../../../../engine/README.md#retried-topics-and-cancellable-agy-work)先修复已定位的主题片段，再请求另一个回答。唯一定位且倒置的锚点互换；不可用的结尾采用相邻边界；重叠的结尾裁剪到后一个已定位的起点。主题归属和录音完整覆盖仍是必要条件，`anchor_counts` 记录修复。重复起点和归属不明确的提案仍被拒绝。

`topics.json` 保留被拒绝的提案，包括格式错误的 JSON 文本和每次尝试的检查结果。一次重试接收被拒绝的回答和明确指出的失败片段。缓存版本 3 在本地重新解析已保存的提案；旧解析器的拒绝和尝试次数少于两次的拒绝不能无限保留回退结果。暂时性失败仍可在下次运行时重试。

来源核查使用引用的试卷及其经原文核实的索引。唯一的临床情景匹配要求临床措辞有充分重合、数量一致，且性别、侧别、否定词和单位一致。审阅和验证将证据明确的标记替换为 Question Bank，或仅包含通过 `exam_years.py` 解析的证据年份的 Past Exams。来源行和题目正文保持完整。措辞不确定、来源未知或匹配冲突时，仍需限定分段修复。结构化审阅结果、验证输出和持久修复日志公开每项自动修正。即使仍有无关检查结果，验证也会保存已确认的标记修复。

[口述主题决策](../feature/2026-10-04-spoken-topics.zh.md)继续规定主题归属和指南组织。[限定审阅决策](2026-10-04-bounded-review-repair.zh.md)继续规定分段保留、图片和取消；本文扩展其回答拒绝策略，并不取代这些机制。

## Alternatives considered

**将每次拒绝交给聊天模型。** 确定性修复也会消耗配额并阻断无人值守任务。

**将每个未匹配的年份降级为 Question Bank。** 情景改写可能隐藏真实的考试证据，因此必须先确定来源，再修改标记。

**接受所有重叠主题图或近似题目匹配。** 重复的片段起点、冲突的数量和不确定的来源身份无法确定归属或出处。

## Consequences

每次运行最多调用模型两次组织主题，并保留用于诊断的回答。标记修复无需模型调用；证据不明确时仍产生限定范围的检查结果。临床匹配属于保守的词汇证据，不能从语义上证明任意改写。临时目录中的合成回归测试覆盖重叠、倒置、缓存重试、被拒绝的提案、带年份和题库证据、不确定的匹配、已保存修正的报告以及暂存分段恢复。私有诊断只读，测试数据不包含其源内容。
