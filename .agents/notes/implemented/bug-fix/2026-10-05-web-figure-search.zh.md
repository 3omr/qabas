# Agent Note: 让真实请求真正找得到外部插图

Status: implemented

[English](2026-10-05-web-figure-search.md) | 中文

## 问题

写作者提出了合理的插图请求，但真实转写从未得到过外部插图。六个原因叠加在一起：长搜索短语（"tension pneumothorax needle decompression second intercostal space"）在 Commons 上没有结果；超过 2 MiB 的原图被拒绝，而大多数医学照片都超过这个大小；没有许可证链接的公有领域与 CC0 文件被拒绝；整节课的插图步骤只有两分钟，而一次 agy 检查就要将近一分钟；写作者的引文必须是精确子串，带省略或拼写变化的引文会让请求被丢弃；而且没有任何记录说明请求为何失败。

## 决策

搜索先用写作者的短语，再依次用其前四个、前两个和最后两个实词，最多四次查询。用 Commons 缩略图（1024 px，来自 thumb.wikimedia.org）代替大原图，SVG 绘图取其 PNG 缩略图。公有领域与 CC0 无需许可证链接；CC BY 与 CC BY-SA 仍须有匹配的许可证链接，包括移植版本。该步骤有十分钟，每个请求最多核验四个候选。引文若是精确子串，或其每个四词以上的片段都与讲座中的某个词窗以 0.85 匹配，即视为有依据。清单旁的 `web-figures-log.json` 记录每个请求的查询、核验结果与最终结果。

## 后果

批准仍由严格的 agy 核验决定，许可证白名单、署名和每课五张的上限不变。候选增多意味着核验调用增多，但每个请求和整个步骤的时限都有上限。
