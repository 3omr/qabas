# Agent Note: 有界转录审阅修复

Status: implemented

[English](2026-10-04-bounded-review-repair.md) | 中文

## Problem

无人值守的课程可能因散落幻灯片渲染文件而无法通过审阅，要求链接当前提取器未选中的图片。手动定义可以指定课件，却没有旧式幻灯片映射。要求聊天模型重新提交 80 KB 转录文本容易产生不完整的工具 JSON，并耗尽桌面循环的两次响应截断上限。

## Decision

[引擎](../../../../engine/README.md#bounded-review-repair)以当前课程标题的提取清单作为幻灯片图片目录。空选择无需链接；每张选中的栅格图片都必须有文件及链接。散落图片和旧标题目录不具有约束权。审阅提取缺失、无效或不完整的清单。提取后的参考文本刷新仅在录音字节和暂存部分分配保持不变时更新布局及精确恢复元数据。手动课件通过定义 id 或标题从 materials 解析；使用 id 提取时写入定义标题目录。

有锚点的问题定位到保留部分；其他问题列出导读图片放置候选部分或全文部分编号。审阅、验证、来源核验和定稿失败要求替换暂存部分，从部分重新审阅并执行两项检查。内联审阅拒绝超过 20,000 UTF-8 字节的提交或已保存草稿。read_draft(staged=true, part=N) 读取保留部分。没有布局的已保存草稿获得 8 KB 修复部分，无需模型重新生成。这些部分保留字节，采用完整导读内容比例检查，不声称与录音片段对齐。agy 拒绝重映射这些已保存修复部分；聊天写作者通过 stage_draft_part 替换有界文本。

[截断恢复决策](../feature/2026-10-02-truncated-tool-call-recovery.zh.md)保留两次响应上限。[外部插图决策](../feature/2026-10-04-web-figures.zh.md)保留审批和归属规则；幻灯片证据采用当前清单目录。这两份记录均未被取代。

## Alternatives considered

**跨录音名称累计散落栅格文件。** 过期渲染文件会约束当前提取器，改名课程会继承旧要求。

**重新提交完整转录。** 提供方可以在分派前截断 JSON，因此服务器大小检查不能单独挽救调用。工具说明必须在生成前选择分部分修复。

**使用 agy 重新生成每份已保存草稿。** 这要求可用逐字稿来源，并重复处理未受影响文本。保留有界现有部分也支持没有逐字稿来源的草稿。

**增加桌面截断重试。** 重复过大调用不会缩小它。引擎恢复保留框架的有界失败语义。

## Consequences

审阅可以花费一次提取尝试，并为转换器错误报告有界重试指引。图片放置仍要求写作者识别讨论主题；诊断不验证语义位置。没有精确锚点的问题需要检查候选部分。内联上限无法阻止工具分派前的截断；模型可见的分部分说明处理更早的失败。

临时目录中的合成测试覆盖过期图片、空及不完整清单、手动课件查找、自动提取、UTF-8 上限、保留部分读取、精确恢复和定向替换。学生文件不会被写入或复制到测试夹具。

## 后续：重试主题与取消

一次真实的 Shock 重做在主题调用上超时并缓存了回退结果，此后每次运行都重复按班级分开的指南。临时性的主题失败现在记录为尝试，并在下次运行时重试；只有带版本的回答拒绝才会被缓存。停止任务并未停止写作：长期运行的 MCP 服务器继续启动 `agy` 分段。长时间的 agy 工作现在在请求的取消范围内运行，收到 `notifications/cancelled` 时终止 agy 进程组，并保留已暂存的分段。
