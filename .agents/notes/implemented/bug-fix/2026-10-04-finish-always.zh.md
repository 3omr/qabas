# Agent Note: 有限讲义修复后自动完成

Status: implemented

[English](2026-10-04-finish-always.md) | 中文

## 问题

讲义级图片省略标记可能让写作和审阅都看不到有效的当前提取结果。只有图片的课件需要 OCR 或视觉读取内容，才能把图片放到对应的口述解释旁。把来源选择题限定为四或五个选项，会拒绝真实的三选项试卷；不确定的第二个引用也可能否决已确认的考试出现记录。修复预算耗尽后的转交可能只留下草稿，而任务栏却显示完成。

## 决策

[引擎](../../../../engine/README.md#deterministic-lecture-jobs)把断网、额度用尽、服务退出登录和录音缺失视为可恢复的学生停止原因。其他问题进入有限修复和自动验证保留流程。每个终态回复都是已完成或学生停止。重复调用以可取消的等待取得当前讲义任务的实际结果。Remote 拒绝 handoff/completed 回复，任务栏只有取得完成里程碑后才显示完成。意外的引擎请求失败保持运行状态，在配置的宽限时间后重试保留内容恢复；重新加载后没有会话的讲义任务以 Continue 恢复。

当前清单和现存栅格图片会恢复先前的图片省略。写作者收到选中的内容图片及带标签的机器读取内容。识别出的标题页和结束页不要求链接。审阅先在全部口述导读段落及其主题中匹配 OCR 词语，再请求有限的段落索引放置方案。方案只插入已知链接，不改写讲述。最终保留流程使用本地匹配，不再请求图片放置模型；未匹配的内容图片在导读末尾作为明确标记的参考保留。无效图片引用会单独报告并删除，不影响有效图片。

历年试题和题库选择题保留原来的二至六个连续选项。生成的 IMP 选择题使用 a–d。出处检查仍会拒绝未修改草稿中的缺失来源或错误试卷引用。修复逐一用原始试卷和试卷支持的索引检查已引用试卷，移除未定位的引用，并在必要时搜索其他本地考核试卷。标签只包含有证据的年份；没有日期的出现记录支持题库标签。真正未定位的问题保留原文和选项，以 IMP 和出处说明呈现，并由引擎签发绑定原文及有序选项的保留记录。模型写入的保留注释不能授予此例外。保留记录先于修复后的草稿或分段发布，使该例外在保存中断后仍然有效。来源字段的修复也纳入分段恢复边界。

保留流程保护有证据的题干、场景、选项和临床子问题。一次有限重写可以修复答案或格式，但不能改变这些原文。重写在预留的本地验证与完成时间窗之前停止。如果考核块仍无效，折叠的来源摘录会保留原文和有证据的标签，并明确省略未验证的答案。只有仍然无效且没有证据支持的考核块会被删除，并报告其标签。无效解释退回完整保存的医生逐字文本。所有保存候选都通过普通的完整讲义、编辑和出处检查；原始分段仍保留在归档中。

[自动修复记录](2026-10-04-engine-self-repair.zh.md)继续拥有主题片段和缓存规则；本决策替代其中不确定出处必须等待分段修复的要求。[有限审阅记录](2026-10-04-bounded-review-repair.zh.md)继续拥有提取出处、保留分段限制和取消规则；本决策增加自动放置，并替代仅依赖写作者放置图片的要求。这两份记录仍部分适用。

## 考虑过的替代方案

**预算耗尽后停止，或把验证转交聊天。** 这会消耗另一个模型的额度，并可能把未保存的讲义报告为完成。

**接受全部声明年份，或删除不确定的问题。** 前者虚构考试出处，后者丢失有用考核。试卷证据决定标签，而未定位的原文可以作为练习保留。

**删除生成答案无效的、有证据的问题。** 答案可以替换，原始考核是学生证据。来源摘录保留考核，同时不声称未验证答案有效。

**把全部图片附在末尾。** 内容图片应位于匹配的口述解释旁。明确标记的未匹配参考只是最终退路。

## 影响

合成回归覆盖不插入任何链接的写作者与图片式 OCR 课件、缺失装饰页栅格图片时的省略恢复、伪造标记拒绝、反复验证中的保留记录持久化、整篇导读匹配、无效放置方案、二至六选项解析、不确定的第二引用、缺失或错误试卷修复、来源摘录保留、修复耗尽、并发讲义锁和使用模拟时间的客户端恢复。只读的 Hyperthyroidism 复现包含十九个内容页链接，排除标题页和结束页；两道已报告的考试选择题保留有证据的年份。私有证据不进入仓库。实际完成的来源预检仍需要网络；离线复现可以验证草稿并在本地渲染最终学生文档，但不能声称已提交到真实资料库。
