# Agent Note: 图像描述的容错

Status: implemented

[English](2026-10-04-figure-description-resilience.md) | 中文

## Problem

Hyperthyroidism 最后一张图片的说明被拒绝后，描述收集在写入提取清单前中止。全部二十张选中幻灯片图片从撰写输入中消失，而讲座流水线可能在未报告丢失的情况下完成。OCR 和说明是否可用，不能决定已渲染图片是否存在。

## Decision

[引擎](../../../../engine/README.md#bounded-review-repair)保留每张已渲染的选中页面。OCR 操作失败、单页超时、视觉提供方不可用或说明被拒绝及无效时，保留已有 OCR 文本，或者使用中性标签 `Slide N: picture slide; no machine-readable description`。读取方法标识 `ocr`、`vision`、`typed` 或 `neutral`；`reading.error` 记录对应页面的失败尝试。中性标签与低置信度 OCR 仅是放置提示，不能当作医生原话。请求取消仍会停止提取。

一次提取共享五分钟，最多调用视觉模型三十次。每页的 OCR 与视觉说明共享六十秒。整体描述预算耗尽后，剩余未缓存的图片页使用中性标签；单页失败不会阻止后续描述。成功缓存的读取结果与幻灯片原有文本无需新的识别调用即可使用。只有无错误的成功 OCR 或视觉读取结果才进入图片哈希缓存；显式提取会重试失败页面。包含失败读取结果的完整清单在准备与审阅时仍有效，普通使用方不会反复渲染幻灯片。

确认已查看图片的视觉说明允许 Markdown 围栏、换行及 `toolAction`/`toolSummary` 完成元数据。说明缩短到八十个单词、六百个字符以内。仍要求明确确认查看图片且视觉文本非空；格式容错不能把拒绝变成观察证据。

初次图片准备会重试一次提取，包括命令成功但未生成有效清单的情况。两次尝试均失败时，持久化讲座局部的幻灯片省略记录，并添加固定任务备注 `Slide pictures could not be prepared; the transcript has none.`。托盘以英语、中文和埃及阿拉伯语翻译该句。基于录音的撰写与验证继续执行，强制检查仍然启用。

[图像缓存与流水线记录](2026-10-04-figure-cache-and-pipeline-steps.zh.md)仍是源文件身份、选择、放置与进度的当前记录。本记录仅取代其中全有或全无的读取策略以及操作级描述超时；仍有独立价值的理由保留在原记录中。

## Alternatives considered

**单条说明失败就中止整个提取。** 描述的可用性弱于图片文件的可用性，不能删除其他选中图片。

**把中性标签缓存为成功描述。** 提供方拒绝或超时可能在以后恢复；仅缓存成功结果可保留重试机会。

**使每个部分描述清单失效。** 准备与审阅会反复栅格化有效幻灯片并丢失可复用的描述，而不是提供其图片。

**接受未确认查看图片的说明。** 格式清理保留明确的查看证据；拒绝仍然记录为失败。

## Consequences

合成 PDF 提取通过假的视觉可执行文件测试真实 OCR 与渲染：一张 OCR 页和一条成功说明不会因最后一页被拒绝而丢失，后续提取只重试失败描述。合成失败覆盖带部分文本的 OCR 错误、单页超时、低置信度 OCR、整体时间及调用次数耗尽、说明格式、有界截断、无效元数据和未确认查看图片。流水线测试通过最终保存与持久化任务备注，覆盖恢复成功、重复错误及缺失清单的子进程结果。托盘测试覆盖固定句子的翻译。

对只读 Hyperthyroidism 幻灯片的临时验证保留二十张选中图片：十九条 OCR 读取结果与第二十一页的一条中性读取结果；清单有效且源文件指纹不变。本会话沙箱阻止 LibreOffice 转换与 agy 的本地主机监听，因此验证使用临时的图片 PDF 渲染器替代转换。这些计数不能证明 LibreOffice 的行为或真实模型的说明；在此环境中仍未验证真实说明的格式。
